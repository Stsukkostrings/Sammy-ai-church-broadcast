Connect it to OBS

  1. Generate the secure link for the overlay channel you use.
  2. In OBS, add a Browser source and paste the generated URL.
  3. Set width 1920 and height 1080 (or match your canvas).
  4. Keep the source background transparent. Do not add an opaque custom CSS background.
  5. Leave “Shutdown source when not visible” off if you want the overlay to stay current between scenes.

The overlay page polls the relay about once per second. OBS does not need the studio login session. A revoked token stops working immediately and the old URL cannot be restored.

Only presentation data is public: reference, text, visibility and loading state. Comments, drafts, account details and unrelated settings are never sent to OBS.
